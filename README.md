#### 🪄 Overview

**CareerCraft AI** is an AI-powered career platform built for Indian students. It features a resume builder, ATS scoring, and a suite of job tools — all powered by Gemini AI — to help students land better opportunities faster.

#### ✨ Features

- 🤖 Gemini AI-powered resume builder
- 📊 ATS score analysis and feedback
- 🎯 Job tools tailored for the Indian market
- ⚡ Fast, clean Next.js architecture
- 🔐 Firebase auth and real-time data
- 💎 Production-ready UI
